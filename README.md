# LAVA Test Definitions

A collection of scripts specifically engineered for compatibility with the
Linux Automated Testing Architecture, aka [LAVA](http://lavasoftware.org/). Includes a test-runner
script for executing tests independently of LAVA. Further information can be
found in the [documentation](docs/index.md).
